## 🚀 如何运行一键基准测试

### 1. 启动服务
确保本地推理服务处于运行状态：
```bash
./start.sh
```

### 2. 执行自动化多模型基准压测
在另一个终端窗口中执行压测工具：

```bash

python benchmark.py --models qwen3.8-27b-8bit-mtp qwen3.8-27b-8bit --rounds 3
```

## 🎯 核心结论与选型建议

1. **日常 IDE 编程首选：`qwen3.8-27b-8bit-mtp`**：
   - 在 128G Mac 上仅占 28.2GB 显存，结合 MTP 投机采样使得代码出字速率突破 **55+ tok/s**，前缀缓存效果需用对应模型实测，旧 `<5ms` 估计不再作为保证。
2. **长文本稳定性首选：`qwen3.8-27b-8bit`**：
   - 纯标准 8-bit 模型，不依赖辅助头，长代码库解析时稳定保持 40+ tok/s。
3. **16-bit 全精度模型仅建议用于基准比对**：
   - 54GB 权重在高并发与 256K 超长上下文下对统一内存带宽消耗较大，日常开发强烈推荐 8-bit 综合版。
