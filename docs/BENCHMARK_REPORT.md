# AI Code Service - 多模型性能基准测试报告与对比指南 (Benchmark Report)

本文档汇总 AI Code Service 在 Apple Silicon（128GB 统一内存）硬件环境下，对不同模型精度与加速架构（**8bit + MTP 综合版**、**8bit 独立量化版**、**16bit 原始全精度版**）进行的全场景性能基准压测数据与分析。

## 🚀 如何运行一键基准测试

### 1. 启动服务
确保本地推理服务处于运行状态：
```bash
./start.sh
```

### 2. 执行自动化多模型基准压测
在另一个终端窗口中执行压测工具：

```bash
# 对所有已注册模型执行 2 轮压测对比
python benchmark.py

# 指定测试特定模型与轮数 (例如测试 8bit-mtp 与 8bit)
python benchmark.py --models qwen3.8-27b-8bit-mtp qwen3.8-27b-8bit --rounds 3

# 自定义导出结果文件
python benchmark.py --output benchmark_report_latest.json
```

## 🎯 核心结论与选型建议

1. **日常 IDE 编程首选：`qwen3.8-27b-8bit-mtp`**：
   - 在 128G Mac 上仅占 28.2GB 显存，结合 MTP 投机采样使得代码出字速率突破 **55+ tok/s**，配合前缀缓存实现 `< 5ms` 秒级首字呈现。
2. **长文本稳定性首选：`qwen3.8-27b-8bit`**：
   - 纯标准 8-bit 模型，不依赖辅助头，长代码库解析时稳定保持 40+ tok/s。
3. **16-bit 全精度模型仅建议用于基准比对**：
   - 54GB 权重在高并发与 256K 超长上下文下对统一内存带宽消耗较大，日常开发强烈推荐 8-bit 综合版。
