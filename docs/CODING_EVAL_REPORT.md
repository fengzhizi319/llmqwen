## 2. 编程能力判断

**可以用于编程，函数级 Python 生成能力较强；更适合有测试约束的编程助手工作流。** HumanEval 完整通过率 96.95%，说明在本地原始断言下，多数函数签名、算法与逻辑任务能一次生成正确实现。MBPP 已测通过率 81.46%，说明遇到参数含义、返回类型、排序和题意隐含约定时仍有明显失误，即使公开测试已经提供也不保证逐例落实。

适合：生成小函数、脚本、明确接口的辅助模块，以及结合实际测试进行代码修改。需要重点复核：参数位置、负数与边界输入、正则完整匹配、返回顺序、长度/索引含义和输出是否截断。长注释或自我解释并不代表实现正确。

本轮评测不执行 OpenCode 的文件读写、终端测试和多轮修复闭环，不能证明跨文件重构、复杂依赖修复或自主完成大型仓库任务的可靠程度。此前工具集成验证与本轮函数分数是不同证据，不合并成工程任务成功率。

### 已复核的典型根因

| 题目 | 诊断 |
| --- | --- |
| humaneval:130 | 为偶数 n 额外计算不需要的奇数索引 n+1，访问 result[n+2] 越界；循环边界与输出边界混淆。 |
| humaneval:132 | 仅使用扫描时的最大括号深度判断嵌套，没有保证匹配并闭合；例如 [[[[[[[[ 或 [[] 被误判为真。 |
| humaneval:140 | 将 1~2 个空格统一替换成一个下划线，错误地把两个空格压缩为一个，而测试要求两个下划线。 |
| humaneval:145 | 排序键只计算 abs(n) 的数字和，忽略题目示例中的负号约定；原题第一个示例就不能通过。 |
| humaneval:163 | 把 even digits 解释为任意偶数，没有限制为单个数字；(10,14) 应为空，却返回 [10,12,14]。 |
| mbpp:1 | 动态规划只考虑上方和左方，遗漏题目测试允许的左上对角移动。 |
| mbpp:13 | 返回所有词频项，未从公开测试推断只需前四项。 |
| mbpp:15 | 只筛选小写字符，未保留每个小写字母后的非小写字符；AbCd 应返回 bC、d。 |
| mbpp:16 | 正则未加首尾锚点，含大写前缀的字符串也被子串匹配判为通过。 |
| mbpp:31 | 使用按频率降序的 nlargest 返回结果，公开测试要求所选元素按堆弹出顺序返回，含同频数值排序。 |
| mbpp:34 | 误把第二参数当预期总和，实际为搜索长度；公开样例不能通过。 |
| mbpp:42 | 只累加重复元素的不同取值，测试要求累加这些取值的全部出现次数。 |
| mbpp:48 | 设置位时至少遍历32位，错误地把原数有效位以外的高位也置1；注释给出正确样例但循环不一致。 |
| mbpp:50 | 把返回元组第一项误作1起始索引，测试要求最短列表长度。 |
| mbpp:55 | 将位置参数定义成(a,r,n)，实际测试约定为(a,n,r)。 |
| mbpp:60 | 把第二参数当最大相邻差，测试约定第二参数是长度、相邻差绝对值为1。 |
| mbpp:77 | 按数字值奇偶分组并判断两组和相等，而公开测试/参考实现要求判断能否被11整除；题文对位置差和判定规则不完整。 |
| mbpp:83 | 直接使用ASCII值求和再取模，未按a=1等字母序号映射。 |
| mbpp:87 | 重复键保留后字典值，测试要求前字典优先。 |
| mbpp:101 | 误将第k个元素理解为第k小元素，排序后改变原数组次序。 |
| mbpp:108 | 直接使用heapq.merge，忽略公开测试实际提供未排序输入。 |
| mbpp:110 | 实现常规区间补集，公开测试却要求每段前间隙及该段末端至总末端的重叠范围，题文和预期存在歧义。 |
| mbpp:111 | 按第一列表顺序输出集合交集，但公开测试固定另一种列表顺序；集合内容正确仍失败。 |
| mbpp:198 | 输出达到2048-token上限，末尾三引号未闭合导致SyntaxError；属于生成预算耗尽后的代码截断。 |

部分 MBPP 题文简略、测试对输出顺序有固定要求，或预期与常见定义不同。仍严格按原断言计分，不修改测试、不修改答案。诊断只覆盖已人工复核的样本；其余失败详见原始记录。

## 5. 实际运行配置与可比性

- 真实模型：`qwen3.8-flash-next-oq4e-mtp-128k`，Qwen4Exp 引擎，非 mock。
- temperature=0，thinking 关闭，max_tokens=2048；每题单次生成，完成的失败代码没有重新采样。
- 完整响应缓存关闭；跨请求前缀缓存开启，4 条/8192 tokens；MTP 开启，深度 3；单并发。
- Python 3.13.15、MLX 0.32.1、mlx-lm 0.31.3、transformers 5.14.1；实际环境和哈希以 manifest/metadata 为准。
- 测试在临时目录的 Python `-I` 子进程执行，超时 15 秒；不是 OS 沙箱。
- 后端恢复重启次数：0；本轮状态为 `stopped_by_user`，不是 `complete`。
- HumanEval 使用本地原始任务测试；MBPP 公开 test_list 同时提供给模型。没有 HumanEval+/MBPP+ 增强测试，也没有隐藏仓库任务验收。
- 数据集公开，可能存在训练污染；提示协议与代码组装会影响分数，不能直接与官方排行榜比较。
